# Standalone Web Frontend — PHI/PII De-Identification Gateway

A modern, transparent, clinical-grade Single Page Application (SPA) providing an interactive user interface for the **HIPAA Safe Harbor PHI/PII De-Identification Gateway**.

The frontend runs independently on port `3000` and communicates directly with the FastAPI Backend API on port `8000` over REST.

---

## Key Features

1. **Multi-Format Document Ingestion**:
   - **Direct Clinical Note Text Editor**: Type or paste notes with real-time character/word counts.
   - **PDF Ingestion (`.pdf`)**: Automatic client-side multi-page text extraction via `pdf.js`.
   - **Word Documents (`.docx`)**: Client-side document extraction via `mammoth.js`.
   - **JSON Payloads (`.json`)**: Ingest structured API requests.
   - **Pre-Loaded Clinical Scenarios**: 1-click loading for Neurology (Parkinson's), Surgical Oncology (Whipple), and Geriatric (Nonagenarian 94yo) test cases.
2. **Transparent Multi-Stage Pipeline Visualizer**:
   - **Stage 1 (Raw Input)**: Formatted input with sensitive identifier detection.
   - **Stage 2 (De-Identified Payload)**: Masked text with color-coded surrogate token badges (`[PATIENT_1]`, `[PROVIDER_1]`, `[DATE_1]`, `[AGE_90+]`).
   - **Stage 3 (Session Mapping Table)**: Searchable, categorised table displaying surrogate token $\rightarrow$ original clinical PHI mapping.
   - **Stage 4 (Foundation LLM Output)**: Raw completion generated by the foundation LLM containing surrogate tokens.
   - **Stage 5 (Final Rehydrated Output)**: Clinical assessment restored with 100% fidelity.
   - **Stage 6 (Telemetry HUD)**: Live Zero-Leak guard verification, entity count, and stage latencies (De-ID, LLM, Rehydration, Total).
3. **Foundation LLM Provider & Parameter Controls**:
   - Live cloud foundation model selection: **Google Gemini (`gemini-3.6-flash`)**, OpenAI (`gpt-4o`), Anthropic (`claude-3-5-sonnet`), and Offline Deterministic Mock.
   - Task prompt selector (Clinical Assessment, SOAP Note, Discharge Regimen, Clinical Q&A).
   - Eponym protection and relative date shifting toggles.

## Quickstart Instructions

### Step 1: Start the Backend Server (Port 8000)
In your first terminal:
```bash
# Navigate to workspace root
cd "c:\Users\ariva\Downloads\PHI  PII de-identification gateway"

# Launch FastAPI backend
uvicorn deid_gateway.api.server:app --host 0.0.0.0 --port 8000
```
Backend will be live at: `http://localhost:8000` (Swagger docs at `http://localhost:8000/docs`).

### Step 2: Start the Frontend Server (Port 3000)
In your second terminal:
```bash
# Start standalone frontend server
python frontend/server.py
```
Open your browser to: **`http://localhost:3000`**.
